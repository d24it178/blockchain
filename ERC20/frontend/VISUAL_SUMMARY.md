## 🔄 Next Steps (5 Minutes)

```
STEP 1: Install (1 minute)
$ cd frontend
$ npm install

STEP 2: Configure (2 minutes)
• Open: src/config/constants.js
• Find: export const TOKEN_CONTRACT_ADDRESS = '0x'
• Replace '0x' with your contract address

STEP 3: Run (1 minute)
$ npm run dev
• Opens http://localhost:3000 automatically

STEP 4: Connect (1 minute)
• Click "Connect MetaMask"
• Approve connection
• Done! 🎉
```
